## Фаза 1. AI-видимость (GEO)

В цели задачи #4 была заявлена «AI-выдача», но ни одного пункта под неё не было.

### 1.1. Политика по AI-краулерам в `robots.txt`

Сейчас `Allow: /` распространяется на всех, включая `GPTBot`, `ClaudeBot`, `PerplexityBot`, `CCBot`, `Google-Extended`, `OAI-SearchBot`. Это не решение, а умолчание.

**Рекомендация:** разрешить явно. Iber — B2B-услуги, попадание в ответы AI-ассистентов работает как канал привлечения, а контента, который стоило бы закрыть, на сайте нет.

- [ ] Перечислить основные AI-краулеры явными `User-agent` блоками с `Allow: /`
- [ ] Комментарием зафиксировать, что это осознанное решение, а не забытый дефолт

### 1.2. `llms.txt`

Машиночитаемая справка в корне: чем занимается Iber, услуги, ключевые страницы, контакты.

- [ ] `llms.txt` с `permalink: /llms.txt`, генерируется из `_config.yml` и списка страниц, чтобы не расходился с сайтом
- [ ] Ссылка на него из `robots.txt`

### 1.3. `FAQPage` schema

Короткие вопрос-ответ блоки хорошо цитируются AI-поиском и дают rich snippet в Google.

- [ ] `development.md` и `products_audit.md` — по 3–4 вопроса, ответы из фактического содержания страниц
- [ ] Разметка через front matter (`faq:` список), рендер в `_includes/structured-data.html` рядом с `Service`
- [ ] Вопросы и ответы вывести и в HTML — schema без видимого контента нарушает правила Google

**Критерий фазы 1:** Rich Results Test видит FAQPage, `llms.txt` и `robots.txt` отдают 200.

## Фаза 4. jQuery и Bootstrap (отдельно, требует визуальной проверки)

**Проблема:** jQuery 1.11.2 (2015). В версиях <3.5 известные XSS. Bootstrap 3.3.2 официально не поддерживает jQuery 3.x.

**Связка:** апгрейд jQuery без апгрейда Bootstrap ломает тему. Нужны обе: Bootstrap 3.4.1 + jQuery 3.7.1.

**Риск:** это вендоренные ассеты темы. `js/main.js` содержит 28 обращений к `$()`, часть API между jQuery 1 и 3 изменилась.

- [ ] Обновить `js/jquery-*.min.js` и `js/bootstrap.min.js` + `css/bootstrap.min.css`
- [ ] Проверить руками: навбар и его дропдаун Products, мобильное меню, скролл-эффекты в `main.js`, страница с `bigimg`
- [ ] Проверить консоль браузера на ошибки

**Делать только с визуальной проверкой в браузере.** Без неё — не делать.
